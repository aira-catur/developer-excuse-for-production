# Developer Excuse for Production

A one-line excuse a developer gives when code breaks in production, written to `entry.txt` for the make.fun bounty [Make the AI Judge Laugh: Developer Excuse](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3).

Run `python3 main.py` — it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` if `MAKEFUN_OUTPUT_DIR` is set, otherwise to `/output/entry.txt`.
